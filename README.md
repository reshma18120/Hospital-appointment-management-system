# Hospital Appointment Management System

A full-stack web application designed to simplify hospital appointment management and patient registration.

## Features
- Patient registration and management
- Appointment scheduling
- Medical record management
- RESTful API integration
- Responsive frontend interface
- MySQL database integration

## Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** React.js
- **Database:** MySQL
- **APIs:** REST APIs
- **Testing:** Postman

## Project Structure
- `backend/` – Spring Boot application
- `frontend/` – React.js application
- `screenshots/` – Application screenshots

## Getting Started
Clone the repository and configure the backend, frontend, and MySQL database according to their respective setup instructions.
